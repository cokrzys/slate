## Hardware Specs

- Modern multi-core processor (i.e. AMD Ryzen 9 5950X)
- 32GB RAM, 64+ recommended
- 1T Main SSD, 2T recommended
- Additional storage as needed (i.e. 4T RAID1 HDD)

## Software Stack

- OS | [Ubuntu Latest LTS Release](https://www.releases.ubuntu.com)
- Database | [PostgreSQL](https://www.postgresql.org/) + [PostGIS](https://postgis.net/)
- Web | [Apache] + [PHP] + [MapServer] + [Leaflet] + [D3]
- Server | [Python] + [GDAL]
